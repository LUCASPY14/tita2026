Proceso de Carga Online

Tiempo total: 13-45 segundos (autenticación + pago)

Gateways soportados: Bancard, Pagopar

Fases del Proceso

  1. Autenticación: Login + 2FA (8-15 segundos)
  2. Selección: Cliente selecciona tarjeta y monto
  3. Procesamiento: Gateway procesa tarjeta de crédito (5-30 segundos)
  4. Webhook: Gateway notifica resultado
  5. Actualización: Sistema actualiza saldo y envía comprobante
